# PHASE 21 — PAPER METHODOLOGY EXTRACTION

Structured extraction of *"Steering Dialogue Dynamics for Robustness against
Multi-turn Jailbreaking Attacks"* (Hu, Robey, Liu; TMLR 02/2026;
arXiv:2503.00187v3).

Every value carries a page/section/table/figure reference into the PDF
(`2503.00187v3.pdf`, 31 pages). Values the paper does not state are marked
`NOT SPECIFIED` — they are **not** filled from the official code here (the
official code's values appear only in the companion register and are labelled as
such).

Extraction was done by reading the paper text with page markers, not from
summaries.

### 1.1 The evaluator's own temperature

The paper states one temperature rule for the whole study (p9). It contains **no
exception for evaluator or judge calls**: the only other mention of "temperature"
in the entire paper is a consistency remark on p5. Therefore the
paper-authoritative setting is **0.7 for every model call**, including the
rubric, refusal and disclaimer evaluators. See
`PHASE_21_METHODOLOGY_DISCREPANCY_REGISTER.md` D-01, which records that the
official implementation instead uses 0.0 and that Guardbound inherited it.

## 3. Reporting conventions in the paper

* All ASR figures are **fractions in [0,1]**, not percentages (e.g. Table 1
  "0.600"), except Figures 5–7 whose axes are percentages.
* Helpfulness: MMLU is percent accuracy; MTBench is the 1–10 score.
* Over-refusal is a fraction of benign prompts refused.
* Tables 1–3 and 5–7 bold "the best and the runner-up" (captions, p8–p11).
* No error bars, CIs, or significance markers anywhere.

## 4. What the paper does not specify

Consolidated list of `NOT SPECIFIED` items, each of which must be either taken
from the official code (and labelled) or declared as a Guardbound decision:

1. Attacker model identity (§5.1 names only the judge).
2. Token / output limits for any call.
3. Seeds and repetition counts.
4. Statistical treatment (no CIs, no tests).
5. Attacker prompt text (delegated to the cited attack papers, p7).
6. η for Tables 5, 9 (per-row), 10, 11.
7. Number of samples in the guardrail F1 evaluation (Table 4).
8. Sampling parameters other than temperature (top_p, penalties).
9. Wall-clock or budget constraints.
10. How refusal/disclaimer judgments were implemented (not described in the paper;
    only the rubric judge is cited, p8).

These gaps are exactly where the official repository is used as a source of
implementation detail — never to override a value the paper states.
